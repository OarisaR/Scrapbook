# Interactive Scrapbook App

A web-based interactive scrapbook built with **React**. Users can decorate the scrapbook with stickers, polaroids, doodles, and alphabet elements on a dynamic canvas.

---

## **Features**

- **Drag & Drop Elements**: Move stickers, polaroids, doodles, and alphabet letters freely on the canvas.
- **Interactive UI**: Clickable elements with hover animations to enhance the scrapbook experience.
- **Customizable Layout**: Users can place elements anywhere on the page for a personalized look.

---

## **Technologies Used**

- **React** for the front-end UI.
